# EIGHTEEN — подарок для Алисы

Интерактивный сайт-подарок на 18-летие (10.10.2026). Одна длинная страница, которую просто листаешь:

«С днём рождения, Лиса!» со штампом 10/10 → торт и желание → омикудзи → вспышка и инстакс → гачапон → письмо → финал.

Все интерактивные штуки живут прямо внутри страницы — никаких меню и переходов.

React + TypeScript + Vite + Tailwind + GSAP. Всё работает без интернета: шрифты, звуки и картинки лежат внутри проекта.

---

## Запуск

Нужен Node.js 18+.

```bash
npm install
npm run dev       # локально: http://localhost:5173
npm run build     # готовый сайт в папке dist/
npm run preview   # посмотреть собранную версию
```

Папку `dist/` можно залить на любой статический хостинг (Netlify Drop, Vercel, GitHub Pages, Cloudflare Pages). Сайт работает из подпапки — пути относительные.

> Микрофон (задуть свечи) браузеры дают только по **https** или на localhost. На всех нормальных хостингах https включён по умолчанию.

## Как заменить тексты

**Весь текст — в одном файле: `src/content/siteContent.ts`.** Компоненты трогать не нужно.

| Что | Где в файле |
|---|---|
| Имя, никнеймы, дата | `recipient` |
| Все фотографии (кроме инстаксов) | `photos` |
| Обложка: «С днём рождения, Лиса!», японская строка, кнопка | `intro` |
| Штамп «Ты 10/10. Прямо как сегодняшняя дата.» | `tenTen` |
| Торт: заголовок, подпись, «Желание принято ♡» | `cake` |
| Омикудзи: заголовок и предсказания | `omikuji`, `fortunes` (`rank` — ступень удачи: `大吉`, `中吉`, `小吉`, `吉`, `末吉`) |
| Фото и подписи инстакса | `instax` |
| Капсулы гачапона | `gacha` |
| Письмо | `letter.paragraphs` — каждый элемент = абзац; `letter.signature` — твоё имя |
| Финал и пасхалка P.S. | `closing` |

Заглушки в квадратных скобках `[...]` — места для твоего текста: письмо, подпись, два мема в гачапоне.

Символ ♡ можно ставить в любой строке — он рисуется отдельной картинкой и никогда не обрезается.

### Капсулы гачапона

Капсулы выпадают **по порядку списка** — поэтому самые важные стоят первыми (10.10 → системные требования → купон на желание). Когда автомат опустеет, он перезаправится и пойдёт сначала. Четыре вида:

```ts
{ kind: 'message', label: 'MEME', title: 'Заголовок', text: 'Текст', note: 'мелкая строчка (необязательно)' }
{ kind: 'wish',    label: 'WISH', title: '...', text: '...' }
{ kind: 'prize',   label: '10.10', rarity: 'Rare capsule', accent: '#d9772b', title: '...', text: '...', note: '...' }  // редкий приз + конфетти
{ kind: 'photo',   label: 'PHOTO', title: '...', text: '...', image: 'media/photos/твоё-фото.jpg' }
```

## Как заменить фото

Все фото — в `public/media/photos/`, пути к ним — в `siteContent.ts` → `photos` и `instax`.

| Ключ | Где на сайте | Формат |
|---|---|---|
| `photos.hero` (`cover.jpg`) | большой портрет на обложке | вертикальное 3:4 |
| `photos.heroDetail` | маленький «полароид» на обложке | квадрат |
| `photos.contactSheet` (`film-01…12`) | лента плёнки в сцене инстакса | горизонтальные 4:3 |
| `instax` (`instax-01…14`) | карточки инстакса | квадрат |
| `photos.gacha` | фото, приклеенное рядом с автоматом | горизонтальное 4:3 |
| `photos.letter` | фото рядом с письмом | вертикальное 3:4 |
| `photos.finale` (`finale.jpg`) | вы вдвоём в финале | горизонтальное 4:3 |
| `photos.details` (`quiet-01…03`) | три маленьких кадра в финале | квадрат |
| `gacha-photo.jpg` | фото-приз в гаче | квадрат |

Рекомендация по размеру: ~1400 px по длинной стороне, JPG, до 400 КБ. Если файла нет, на его месте будет аккуратная заглушка.

## Звук

Музыки на сайте нет. Остались только короткие звуковые эффекты (затвор камеры, щелчок гачи, шорох бумаги, печать), они синтезируются прямо в браузере и включаются после первого нажатия.

## Японские символы

Японский шрифт урезан только до символов, которые есть на сайте (так он весит 15 КБ вместо 7 МБ). Если добавишь новые японские слова (например, другую ступень омикудзи), пересобери шрифт:

```bash
pip install fonttools brotli
pyftsubset NotoSerifJP-Regular.otf --text="все японские символы сайта" \
  --flavor=woff2 --output-file=src/assets/noto-serif-jp-Regular.woff2
```

(То же для `SemiBold`.) Плакатный шрифт Dela Gothic One лежит в `src/assets/dela-gothic-one.woff2` и тоже урезан до символов сайта — его пересобирать так же. Исходник шрифта — [Noto Serif JP](https://fonts.google.com/noto/specimen/Noto+Serif+JP). Если не пересобрать — новые символы просто покажутся системным шрифтом.

## Как устроено

```
src/
  content/siteContent.ts   ← весь контент
  App.tsx                  ← порядок сцен на странице
  scenes/                  ← Intro, Cake, Omikuji, Instax, Gacha, Letter, Closing
  components/objects.tsx   ← SVG коробки омикудзи и камеры
  components/ui.tsx        ← ленты, штампы, картинки с заглушкой, веточка
  lib/audio.ts             ← синтезированные звуковые эффекты
  lib/exportPhoto.ts       ← сохранение инстакса в PNG (canvas)
  lib/confetti.ts          ← бумажное конфетти
public/media/{photos,audio,graphics}/
```

Детали, которые стоит знать:

- **Свечи.** Микрофон слушает громкость (после короткой калибровки под шум комнаты), а не именно дыхание — поэтому рядом всегда есть кнопка «зажми и держи», которая работает одинаково хорошо. Если доступ к микрофону запрещён или браузер его не поддерживает, сайт просто предлагает кнопку. Микрофон отключается сразу после того, как свечи погасли, и при выходе из сцены.
- **Инстакс.** Карточки перетаскиваются пальцем (pointer events, без системного drag-and-drop), тап переворачивает. «PNG» открывает готовую карточку с кнопками «Скачать» / «Поделиться»; на iPhone можно также удержать картинку и выбрать «Сохранить в Фото».
- **Скролл.** Обычная прокрутка без закреплений и перехвата. Сцены сшиты бегущими лентами; анимации запускаются, когда сцена появляется на экране.
- **Инстакс.** Карточки никогда не пропадают. На телефоне фото двигается за полоску скотча, вертикальный свайп по фото листает страницу. Кнопка «Собрать» раскладывает всё обратно.
- **Telegram / iPhone.** Сайт — обычная https-страница, ничего не требует. Во встроенном браузере Telegram микрофона может не быть — тогда свечи задуваются кнопкой «зажми и держи».
- **Reduced motion.** Если в системе включено «уменьшить движение», анимации сокращаются до мгновенных переходов, конфетти не показывается.
